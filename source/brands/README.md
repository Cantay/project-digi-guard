# Marka logoları

Resmî logo dosyalarını buraya koyun (şeffaf arka planlı SVG ya da PNG). Ad, content/site.json → integrations.brands[].slug ile aynı olmalı:

hikvision · dahua · imou · ebs · ewelink · meta · uniview

Örnek: `hikvision.svg`. Dosya yoksa sitede markanın adı yazı olarak görünür. Logolar yeniden çizilmez, rengi ve oranı değiştirilmez.
